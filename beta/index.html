About

Versionbeta · 2026-10-16 17:11 · cbaa3ac+

Tasks is a small task app built on one markdown file in a GitHub repository. It has no server and no account: the page talks to GitHub directly. Phone reminders come from a GitHub Action and ntfy, a free push service.

The demo

Without a token, the app shows example tasks. Each task shows one feature, and some explain it in their notes. Your changes stay in this browser. The demo starts again each day, or at once with Reset.

  • Views. Agenda and Matrix (urgent × important). Agenda shows Today, 3 days, Week, Month or All; tap a day of the strip to see that day, then a later day for a range. Each list also has List, Board, Lanes and Matrix views, with sections.
  • Quick add. Type a sentence: Call the bank tomorrow 9am every week #money !1 @Life. The parser reads dates, times, repeats, tags, priority and the list, in English or French.
  • Repeats. day, weekday, week, month, year, 3d, 2w, mon,thu, 1mon (first Monday), -1fri (last Friday), 1wd (first office day of the month, Monday to Friday). A deadline by: moves with the date. Completing a repeating task moves it to its next date.
  • Tasks. Notes, checklists, priority, tags, and an In progress state.
  • Keyboard. n adds a task, 1–4 change the view, the arrows move through the open panel.

The file format

Each ## heading is a list, and each ### heading is a section. One task per line, every token optional except the title:

- [ ] Title due:2026-10-20 at:18:00 every:week !1 #tag ^id
  A note line, indented by two spaces
  - [ ] A checklist item

A done task reads - [x] … done:2026-10-20, a task in progress reads - [/] …. You can edit the file by hand, in Obsidian, or with an AI agent: the app keeps every line it does not change.

A heading can end with a type. ## Habits ~habits is a habits list: each habit repeats, a missed one never goes overdue, streak:5 counts the check-ins in a row and a note line ✓ 2026-10-19 2026-10-20 logs them (streak:off keeps only the reminder). ## Groceries ~stock is a stock list: open = to buy, checked = in stock.

The sliders button at the top right opens View options: group a list by section, tag, priority or date, sort it, show empty sections and the tasks done this week, hide chips and the create buttons (the search ⌘K still creates tasks, lists and sections), show note lines, set the density. The address bar keeps the view, so a reload or a link opens the same list or task (#list/work/board, #agenda/week).

Use your own list

  1. Create a private repository on GitHub, for example my-tasks.
  2. Add a file Tasks.md at its root. Start from the demo file, or from one line: ## Inbox.
  3. Create a fine-grained token. Under Repository access, pick Only select repositories and choose that one repository. Under Permissions, set Contents: Read and write.
  4. Open Settings here. Paste the token, then type owner/my-tasks, the branch main and the file Tasks.md.

The token stays in this browser and goes only to GitHub. Each change is one commit in your repository, so you keep the full history. On a phone, use Share → Add to Home Screen to install the app.

Phone reminders

A task with a time sends a notification at that time. A task with a date and no time shows in a morning digest at 08:00. Set them up once:

  1. Install the ntfy app on your phone. Subscribe to a long random topic name, such as tasks-7f3a91c2e8. Anyone who knows the name can read it, so keep it secret.
  2. Copy the folder reminders/ of the code repository into your repository. Move reminders/tasks-reminders.yml to .github/workflows/.
  3. In your repository, open Settings → Secrets and variables → Actions. Add the secret NTFY_TOPIC with your topic name.

The Action runs after each change to Tasks.md and every 6 hours. It schedules each reminder in ntfy up to 3 days ahead. Change the time zone and the digest hour in the workflow file.
